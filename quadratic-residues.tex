\chapter{Quadratic Residues}\label{chapter:quadratic-residues}

\section{Quadratic Congruences}

A \emph{quadratic congruence} is a congruence of the form
\begin{equation*}
  ax^2 + bx + c \equiv 0 \pmod{n},
\end{equation*}
where $a$ is assumed to be relatively prime to $n$. To build intuition for such quadratic congruences, let's first recall how to solve a quadratic equation
\begin{equation*}
  ax^2 + bx + c = 0,
\end{equation*}
where $a\neq 0$. Since we have assumed that $a$ is nonzero, we may divide through by $a$ to obtain the equation
\begin{equation*}
  x^2 + \frac{b}{a}x = -\frac{c}{a}.
\end{equation*}
Completing the square, gives us the equation
\begin{equation*}
  \left(x + \frac{b}{2a}\right)^2 = \frac{b^2}{4a^2}-\frac{c}{a}=\frac{b^2-4ac}{4a^2}.
\end{equation*}
This equation has the familiar solutions
\begin{equation*}
  x = \frac{-b\pm\sqrt{b^2-4ac}}{2a}.
\end{equation*}
The number $\Delta:=b^2-4ac$ is called the \emph{discriminant} of the quadratic equation $ax^2+bx+c=0$. For example, the quadratic equation $x^2 - x - 1$ has discriminant $5$, and therefore its solutions are
\begin{equation*}
  x=\frac{1\pm\sqrt{5}}{2}.
\end{equation*}
Since the square root $\sqrt{k}$ of an integer $k$ is an integer if and only if $k$ is a perfect square, we obtain the following theorem:

\begin{theorem}
  Consider the quadratic equation with integer coefficients
  \begin{equation*}
    ax^2 + bx + c = 0,
  \end{equation*}
  where $a\neq 0$. This equation has a rational solution if and only if the discriminant $\Delta=b^2-4ac$ is a perfect square.
\end{theorem}

Now consider an odd prime $p$. Recall from \crefnamed{theorem:lagranges-theorem}{Lagrange's Theorem} that a polynomial congruence
\begin{equation*}
  f(x)\equiv 0\pmod{p}
\end{equation*}
has at most $n$ solutions, where $n$ is the degree of $f$. It follows that a quadratic congruence modulo a prime has at most two solutions. In the following theorem, which is analogous to the previous theorem, we show that a quadratic congruence modulo an odd prime is solvable if and only if its discriminant is a perfect square.

The situation is slightly different for the prime $p=2$, since the quadratic congruence
\begin{equation*}
  x^2+x+1\equiv 0\pmod{2}
\end{equation*}
has no solutions, even though the discriminant is a perfect square. Indeed, as we will see in the proof below, we will rely on the invertibility of $2$ modulo $p$ to solve general quadratic congruences modulo $p$, which is not possible if $p=2$.

\begin{theorem}\label{theorem:quadratic-congruence-mod-prime}
  Consider a quadratic congruence
  \begin{equation*}
    ax^2 + bx + c \equiv 0 \pmod{p}
  \end{equation*}
  modulo an odd prime $p$, where $a\nequiv 0\pmod{p}$. This quadratic congruence is solvable if and only if the discriminant $\Delta=b^2-4ac$ is congruent to a square modulo $p$.
\end{theorem}

\begin{proof}
  Given that $p$ is an odd prime and that $a\nequiv 0\pmod{p}$, it follows that $4a$ is invertible modulo $p$. The quadratic congruence in the statement of the theorem is therefore solvable if and only if the quadratic congruence
  \begin{equation*}
    4a^2x^2 + 4abx + 4ac \equiv 0 \pmod{p}
  \end{equation*}
  is solvable. Given a solution of this quadratic congruence, we calculate
  \begin{align*}
    (2ax + b)^2 & = 4a^2x^2 + 4abx + b^2 \\
                & = 4a^2x^2 + 4abx + 4ac + b^2 - 4ac \\
    & \equiv b^2 - 4ac
  \end{align*}
  modulo $p$. This shows that the discriminant is congruent to a square modulo $p$.

  On the other hand, if the discriminant is congruent to a square modulo $p$, as in
  \begin{equation*}
    y^2\equiv b^2-4ac\pmod{p},
  \end{equation*}
  then we find, entirely analogous to the case of quadratic equations, that
  \begin{equation*}
    x=\frac{-b\pm y}{2a}
  \end{equation*}
  solves the quadratic congruence modulo $p$. We leave the verification that such $x$ is indeed a solution to the reader.
\end{proof}

\section{Quadratic Residues}

We have seen in the previous section that in order to solve a quadratic congruence
\begin{equation*}
  ax^2 + bx + c \equiv 0 \pmod{p}
\end{equation*}
modulo an odd prime $p$, we need to determine whether the discriminant $\Delta=b^2-4ac$ is congruent to a square modulo $p$. In other words, we need to determine whether the discriminant is a quadratic residue modulo $p$, which is defined as follows:

\begin{definition}
  An integer $a$ is said to be a \emph{quadratic residue} modulo $n$ if there is an integer $x$ such that the congruence
  \begin{equation*}
    x^2\equiv a\pmod{n}
  \end{equation*}
  holds. If no such $x$ exists, we say that $a$ is a \emph{quadratic nonresidue} modulo $n$.
\end{definition}

For example, $0$ and $1$ are always quadratic residues modulo any natural number $n$. The number $0$ is called the \emph{trivial quadratic residue}, and we will mostly be interested in the nontrivial quadratic residues.

Modulo $3$, the only quadratic residues are $0$ and $1$, since the quadratic congruence $x^2\equiv 2\pmod{3}$ does not have solutions. In other words, every square is either divisible by $3$ or congruent to $1$ modulo $3$.

Similarly, $0$ and $1$ are the only quadratic residues modulo $4$; that is, no square number can be congruent to $2$ or $3$ modulo $4$. Indeed, the square of an even number is divisible by $4$ and the square of an odd number is congruent to $1$ modulo $4$.

Modulo $5$ we find that $0$, $1$, and $4$ are quadratic residues, and we can similarly list all the quadratic. The following table lists the nontrivial quadratic residues modulo $n$ from $4$ to $10$, where $0$ is included as a quadratic residue if it is the square of a nonzero integer modulo $n$:
\begin{center}
  \begin{tabular}{lllllllll}
    $n$ & $4$ & $5$ & $6$ & $7$ & $8$ & $9$ & $10$ \\ \midrule
    quadratic residues & $0,1$ & $1,4$ & $1,3,4$ & $1,2,4$ & $0,1,4$ & $0,1,4,7$ & $1,4,5,6,9$
  \end{tabular}
\end{center}

If we have access to a primitive root $g$ of a prime $p$, then it is easy to characterize the nontrivial quadratic residues of $p$ as the even powers of $g$. This has the immediate corollary that exactly half of the nonzero integers modulo $p$ are quadratic residues.

\begin{proposition}\label{proposition:quadratic-residue-pairity-exponent-primitive-root}
  Consider a prime $p$ with a primitive root $g$. An integer $a\nequiv 0\pmod{p}$ is a nontrivial quadratic residue modulo a $p$ if and only if it is an even power of $g$.
\end{proposition}

\begin{proof}
  Consider a primitive root $g$ modulo $p$. If $a\equiv g^{2k}\pmod{p}$, then $a$ is clearly a quadratic residue modulo $p$. On the other hand, if $x^2\equiv a\pmod{p}$, and $x\equiv g^k\pmod{p}$, then we have $a\equiv g^{2k}\pmod{p}$.
\end{proof}

\begin{corollary}
  There are exactly $(p-1)/2$ nontrivial quadratic residues modulo $p$ in the set $\{1,\ldots,p-1\}$, and exactly $(p-1)/2$ quadratic nonresidues.
\end{corollary}

We now turn our attention to the quadratic congruence $x^2\equiv 1\pmod{n}$. When $n$ is not a prime number, this congruence can have more solutions than its degree. For example, the quadratic congruence $x^2\equiv 1\pmod{8}$ has four distinct solutions. Similarly, the quadratic congruence $x^2\equiv 1\pmod{15}$ we have the four solutions
\begin{equation*}
  1^2\equiv 1\pmod{15},\quad 4^2\equiv 1\pmod{15},\quad 11^2\equiv 1\pmod{15},\quad\text{and}\quad 14^2\equiv 1\pmod{15}.
\end{equation*}
In the following theorem we give a precise count of the number of solutions to this quadratic congruence.

\begin{theorem}
  Consider a positive integer $n$, and let $\omega(n)$ be the number of its prime divisors. Then the number of integers $0<x<n$ such that $x^2\equiv 1\pmod{n}$ is $2^{\omega(n)+\varepsilon(n)}$, where
  \begin{equation*}
    \varepsilon(n):=
    \begin{cases}
      0 & \text{if $n$ is odd,}\\
      -1 & \text{if $n$ is even but not divisible by $4$,}\\
      0 & \text{if $n$ is divisible by $4$ but not by $8$,}\\
      1 & \text{if $n$ is divisible by $8$.}
    \end{cases}
  \end{equation*}
\end{theorem}

\section{Legendre Symbols}

The fact that the integers $1$, $2$, \ldots, $p-1$ can be split into the sets of quadratic residues and quadratic nonresidues, which are both of size $(p-1)/2$, suggests there is an interesting dichotomy between them. We can explore this further using primitive roots. If $g$ is a primitive root modulo $p$, then the quadratic residues are precisely those integers modulo $p$ that can be written as an even power of $g$, and the quadratic nonresidues are precisely those integers modulo $p$ that can be written as an odd power of $g$. Now recall that
\begin{equation*}
  g^mg^k=g^{m+k},
\end{equation*}
and that the parity of the sum of two integers can be expressed in terms of the parity of the summands: The summands $m$ and $k$ have the same parity if and only if $m+k$ is even, and likewise they have distinct parity if and only if $m+k$ is odd. This leads to the following multiplication rule of quadratic residues:

\begin{proposition}\label{proposition:multiplicativity-quadratic-residues}
  Consider two integers $a$ and $b$ modulo a prime $p$, both not divisible by $p$. Then we have
  \begin{enumerate}
  \item If both $a$ and $b$ are quadratic residues, or both are quadratic nonresidues, then $ab$ is a quadratic residue.
  \item If one of $a$ and $b$ is a quadratic residue and the other is a quadratic nonresidue, then $ab$ is a quadratic nonresidue.
  \end{enumerate}
\end{proposition}

The previous proposition was also observed by Adrien-Marie Legendre, who published his findings in \emph{Essai sur la th\'eorie des nombres} in 1798 \cite{legendre1798}. In this work, he also formulated the quadratic reciprocity theorem, and attempted to prove it. His approach, however, relied on unproven assumptions about certain functions, and was therefore incomplete.

\begin{definition}
  The \emph{Legendre symbol} of an integer $a$ modulo a prime $p$, such that $p\nmid a$, is defined by
  \begin{equation*}
    \legendre{a}{p} :=
    \begin{cases}
      1 & \text{if $a$ is a quadratic residue modulo $p$}\\
      -1 & \text{if $a$ is a quadratic nonresidue modulo $p$.}
    \end{cases}
  \end{equation*}
\end{definition}

An immediate consequence of \cref{proposition:quadratic-residue-pairity-exponent-primitive-root} is that
\begin{equation*}
  \legendre{a}{p}=(-1)^{\ind_g(a)}
\end{equation*}
for any primitive root $g$ modulo $p$. Using Legendre symbols, we can reformulate \cref{proposition:multiplicativity-quadratic-residues} succinctly as the \emph{multiplicative law of Legendre symbols}: For any two integers $a$ and $b$, both not multiples of $p$, the equality
\begin{equation*}
  \legendre{ab}{p}=\legendre{a}{p}\legendre{b}{p}
\end{equation*}
holds. In fact, the Legendre symbol is the unique surjective function from the integers $\{1,\ldots,p-1\}$ to $\{1,-1\}$ with this property.

\begin{theorem}
  Consider an odd prime $p$. Then the function $a\mapsto \legendre{a}{p}$ is the unique surjective function $f:\{1,\ldots,p-1\}\to\{1,-1\}$ preserving multiplication, in the sense that
  \begin{equation*}
    f(ab)=f(a)f(b)
  \end{equation*}
  for every two nonzero integers $a$ and $b$ modulo $p$\footnote{In the language of group theory: The Legendre symbol is the unique surjective group homomorphism from the group $(\mathbb{Z}/p\mathbb{Z})^{\times}$ of invertible elements modulo $p$ to the $2$-element group $S_2$.}.
\end{theorem}

\begin{proof}
  We have already seen that the Legendre symbol is a surjective function preserving multiplication. Thus, our task is now to show that if $f:\{1,\ldots,p-1\}\to\{1,-1\}$ is any surjective function preserving multiplication, then $f$ is the Legendre symbol. Notice that for any primitive root $g$ modulo $p$, we have
  \begin{equation*}
    f(g^m)=f(g)^m.
  \end{equation*}
  since every element is of the form $g^m$, this implies that $f(g)=-1$. Then it follows that $f(g^m)=1$ if and only if $m$ is even, i.e., $f(a)=1$ if and only if $a$ is a quadratic residue modulo $p$.
\end{proof}

\begin{example}
  Recall that $2$ is a primitive root of the prime $13$, and is therefore a quadratic nonresidue. Using that the square of a Legendre symbol is always $1$, we can compute the Legendre symbol $\legendre{8}{13}$ as follows:
  \begin{equation*}
    \legendre{8}{13}=\legendre{2}{13}\legendre{2}{13}\legendre{2}{13}=\legendre{2}{13}=-1.
  \end{equation*}
  Thus, $8$ is a quadratic nonresidue modulo $13$.

  Similarly, using that $5\equiv 18\pmod{13}$ we can compute the Legendre symbol $\legendre{5}{13}$ as follows:
  \begin{equation*}
    \legendre{5}{13}=\legendre{18}{13}=\legendre{2}{13}\legendre{3}{13}\legendre{3}{13}=\legendre{2}{13}=-1.
  \end{equation*}
  We see that $5$ is also a quadratic nonresidue modulo $13$.

  On the other hand, again using that the square of a Legendre symbol is always $1$, we can compute the Legendre symbol $\legendre{3}{13}$ as follows:
  \begin{equation*}
    \legendre{3}{13}=\legendre{3}{13}\legendre{3}{13}\legendre{3}{13}=\legendre{27}{13}=\legendre{1}{13}=1.
  \end{equation*}
  Thus we see that $3$ is a quadratic residue modulo $13$. In fact, we can readily verify that $3\equiv 4^2\pmod{13}$. The set of all nontrivial quadratic residues modulo $13$ is
  \begin{equation*}
    \{1,3,4,9,10,12\}.
  \end{equation*}
\end{example}

\section{Euler's Criterion}

Euler had a deep understanding of numbers that are congruent to a square modulo a prime. In 1748 he had published a result now known as \emph{Euler's criterion}, which characterized precisely the squares modulo a prime.

\begin{theorem}[Euler's Criterion]\label{theorem:eulers-criterion}
  Consider an integer $a$ and an odd prime $p$. Then we have
  \begin{equation*}
    a^{\frac{p-1}{2}} \equiv \legendre{a}{p}\pmod{p}
  \end{equation*}
\end{theorem}

\begin{proof}
  First note that \crefnamed{theorem:fermats-little-theorem}{Fermat's Little Theorem} gives that if $b:=a^{\frac{p-1}{2}}$, then
  \begin{equation*}
    b^2\equiv 1\pmod{p}.
  \end{equation*}
  This implies that $b\equiv\pm1\pmod{p}$.
  
  To prove the congruence in Euler's Criterion, consider a primitive root $g$ modulo $p$, and suppose that $g^m\equiv a\pmod{p}$. Then $a$ is a quadratic residue if and only if $m$ is even. Also, we note that
  \begin{equation*}
    \frac{m(p-1)}{2}
  \end{equation*}
  is a multiple of $p-1$ if and only if $m$ is even. Thus we see that
  \begin{equation*}
    a^{\frac{p-1}{2}}\equiv 1\pmod{p}.
  \end{equation*}
  if and only if $a$ is a quadratic residue, and it is congruent to $-1$ otherwise.
\end{proof}

Using Euler's Criterion, we can give a new proof of \cref{theorem:quadratic-character-neg-1}. In the language of quadratic residues, \cref{theorem:quadratic-character-neg-1} states that $-1$ is a quadratic residue modulo an odd prime $p$ if and only if $p\equiv 1\pmod{4}$. In other words,
\begin{equation*}
  \legendre{-1}{p}= 
  \begin{cases}
    1 & \text{if }p\equiv 1\pmod{4} \\
    -1 & \text{if }p\equiv 3\pmod{4}.
  \end{cases}
\end{equation*}
This description of the quadratic character of $-1$ is also called the \emph{first supplement} of the law of quadratic reciprocity.

\begin{proof}[Proof of \cref{theorem:quadratic-character-neg-1} using Euler's Criterion.]
  By \crefnamed{theorem:eulers-criterion}{Euler's Criterion}, it follows that $-1$ is a quadratic residue modulo $p$ if and only if
  \begin{equation*}
    (-1)^{\frac{p-1}{2}}\equiv 1\pmod{p}.
  \end{equation*}
  Since $(-1)^m\equiv 1\pmod{p}$ if and only if $m$ is even, it follows that $-1$ is a quadratic residue modulo $p$ if and only if $\frac{p-1}{2}$ is even, which holds if and only if
  \begin{equation*}
    p\equiv 1\pmod{4}.\qedhere
  \end{equation*}
\end{proof}

\section{Euler's Prime-Generating Polynomial}

In the early 1770s, Leonhard Euler devised his famous prime-generating polynomial
\begin{equation*}
  n^2 + n + 41.
\end{equation*}
This polynomial produces prime numbers for any $0\leq n \leq 39$. Note that
\begin{equation*}
  40^2 + 40 + 41 = 40(40+1) + 41 = 41^2
\end{equation*}
isn't prime anymore. We could easily imagine Euler pondering one day over the question of creating a quadratic polynomial that returns a surprising amount of primes, and it would be natural to wonder how he might have approached the problem.

Of course, there is no polynomial $f(x)$ other than a constant polynomial such that $f(x)$ is a prime number for every integer $x$.

\begin{proposition}
  If every value of a polynomial $f(x)$ is prime, then $f(x)$ is constant.
\end{proposition}

\begin{proof}
  Suppose $f(x)$ is a polynomial, all of whose values are prime. Then in particular $p:=f(0)$ is prime. Then $p\mid f(kp)$ for every integer $k$. Since each value of $f$ is prime, it follows that $f(kp)=p$ for every integer $k$. This implies that $f(x)-p$ has infinitely many roots, i.e., $f(x)$ is the constant polynomial with value $p$.
\end{proof}

As a reasonable starting point for our search, we take three consecutive primes of the form
\begin{equation*}
  q,~q+2,~\text{and}~q+6.
\end{equation*}
By \crefnamed{theorem:lagranges-interpolation-theorem}{Lagrange's Interpolation Theorem}, there is only one polynomial $f$ such that $f(n)$ assumes those values for $n=0,1,2$:
\begin{equation*}
  f(n)=n^2+n+q.
\end{equation*}
Thus we are faced with the task of finding a prime $q$ such that $n^2+n+q$ is prime for $0\leq n \leq q-2$. One thing to note is that if the number
\begin{equation*}
  n^2 + n+q
\end{equation*}
is composite for some $0\leq n\leq q-2$, then it must have a prime factor below $q$. Indeed, we have $n^2+n+q< q^2$ for such $n$, so if $n^2+n+q$ is composite for any $0\leq n\leq q-2$ then it has an odd prime factor $p<q$. In other words, we want to find an odd prime $q$ such that
\begin{equation*}
  n^2+n+q\nequiv 0\pmod{p}
\end{equation*}
for any odd prime $p<q$. Recall from \cref{theorem:quadratic-congruence-mod-prime} that such an incongruence holds if and only if the discriminant $\Delta=1-4q$ is a quadratic nonresidue modulo $p$ for any odd prime $p<q$. By \crefnamed{theorem:eulers-criterion}{Euler's Criterion}, this observation finally narrows our search: We are looking for a prime $q$ such that
\begin{equation*}
  (1-4q)^{\frac{p-1}{2}} \equiv -1 \pmod{p}
\end{equation*}
for any odd prime $p<q$.

We can now discover prime-generating polynomials of the form $n^2 + n + q$ by computing the integer $1-4q\pmod{p}$ for all odd primes $3<p<q$. If we can find a prime $p$ such that $1-4q$ is a quadratic residue mod $p$, we may discard that prime from the remainder of the search. This process resulted in \cref{table:discriminants-prime-generating-polynomials}, which reveals that the following polynomials are prime-generating polynomials, in the sense that they yield prime numbers for all inputs $0\leq n \leq q-2$:
\begin{align*}
  & n^2 + n + 2 & & n^2 + n + 11 \\
  & n^2 + n + 3 & & n^2 + n + 17 \\
  & n^2 + n + 5 & & n^2 + n + 41.
\end{align*}
A deep theorem, the Baker--Heegner--Stark Theorem, shows that these are the only prime-generating polynomials of the form $n^2 + n + q$. In other words, Euler had in fact found the quadratic polynomial of this kind with the longest streak of primes! For this reason, the number $41$ is sometimes called Euler's lucky prime.

    a^m\equiv \legendre{a}{p}\pmod{p}\qquad\Leftrightarrow\qquad m\equiv\frac{p-1}{2}\pmod{\ord_p(a)}.
  \end{equation*}
  \exercise
  \begin{subexenum}
  \item Show that $\legendre{-3}{p}=1$ if and only if $p\equiv 1\pmod{3}$.
  \item For any finite set $p_1,\ldots,p_k$ of primes congruent to $1$ modulo $3$, use the prime divisors of
    \begin{equation*}
      n=(p_1\cdots p_k)^2+3
    \end{equation*}
    to show that there is a prime $q\equiv 1\pmod{3}$ that is not already among the primes $p_1,\ldots,p_k$. Conclude that there are infinitely many primes congruent to $1$ modulo $3$.
  \end{subexenum}
  \exercise \label{exercise:legendre-5}
  \begin{subexenum}
  \item Show that $\legendre{5}{q}=\legendre{q}{5}$ holds for every prime $q\neq 5$. In other words, which two congruence classes $1$, $2$, $3$, or $4$ modulo $5$ contain the primes $q$ such that $5$ to be a quadratic residue modulo $q$?
  \item For any finite set of primes $p_1,\ldots,p_k$ congruent to $1$ modulo $5$, use the prime divisors of
    \begin{equation*}
      (2p_1\cdots p_k)^4+5
    \end{equation*}
    to show that there is a prime $q\equiv 1\pmod{5}$ that is not already among the primes $p_1,\ldots,p_k$. Conclude that there are infinitely many primes congruent to $1$ modulo $5$.
  \end{subexenum}
  \exercise Show that the polynomial $n^2-79n+1601$ returns primes for all $0\leq n\leq 79$.
  \exercise
  \begin{subexenum}
  \item Consider a prime $p\equiv 1\pmod{4}$. Show that $g$ is a primitive root modulo $p$ if and only if $-g$ is a primitive root modulo $p$.
  \item Consider a prime $p\equiv 3\pmod{4}$. Show that $g$ is a primitive root modulo $p$ if and only if $-g$ has order $(p-1)/2$ modulo $p$.
  \end{subexenum}
  \exercise Consider an odd prime $p$. Show that there are exactly
  \begin{equation*}
    \frac{(p-1)p^{m}}{2}
  \end{equation*}
  quadratic residues modulo $p^{m+1}$ that are not divisible by $p$.
  \exercise Consider an odd prime $p$ and two positive integers $m$ and $n$. Show that any number $a$ not divisible by $p$ is a quadratic residue modulo $p^m$ if and only if it is a quadratic residue modulo $p^n$.
  \exercise Consider an integer $a$ and a prime $p$. Show that $-a$ is a quadratic residue modulo $p$ if and only if $p$ divides a number of the form $x^2+ay^2$.
  \exercise Recall that a Fermat prime is a prime of the form $F_n:=2^{2^n}+1$. Show that the following are equivalent for a prime number $p$:
  \begin{enumerate}
  \item The prime $p$ is a Fermat prime.
  \item Every quadratic nonresidue modulo $p$ is a primitive root.
  \end{enumerate}
  \exercise Recall that a prime $p$ is said to be a Sophie Germain prime if the number $q=2p+1$ is prime.
  \begin{subexenum}
  \item Show that $p$ is a Sophie Germain prime if and only if every quadratic nonresidue modulo $q$ apart from $-1$ is a primitive root modulo $q$.
  \item Show that if $p\equiv 1\pmod{4}$ is a Sophie Germain prime, then $2$ is a primitive root modulo $q$.
  \item Show that if $p\equiv 3\pmod{4}$ is a Sophie Germain prime, then $-2$ is a primitive root modulo $q$.
  \end{subexenum}
